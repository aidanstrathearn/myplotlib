# cargo-myplotlib

`cargo-myplotlib` builds an embeddable Myplotlib WebAssembly package. Install
it from the Myplotlib checkout:

```sh
cargo install --path crates/cargo-myplotlib
```

Then run it as a Cargo subcommand:

```sh
cargo myplotlib build-web \
  --manifest-path examples/two_views/Cargo.toml \
  --out-dir examples/two_views/pkg \
  --release \
  --locked
```

The output contains a public `app.js` module, Myplotlib's private loader, and
the bindings and WebAssembly generated by wasm-pack. The host page imports
only `app.js`.

This initial command expects `wasm-pack` to be installed. It does not yet
configure WebAssembly threads, initialize Rayon, generate standalone HTML, or
serve the output.
