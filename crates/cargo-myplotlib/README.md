# cargo-myplotlib

`cargo-myplotlib` builds an embeddable Myplotlib WebAssembly package. Install
it from the Myplotlib checkout:

```sh
cargo install --path crates/cargo-myplotlib --locked --force
cargo myplotlib --version
```

Then run it as a Cargo subcommand:

```sh
cargo myplotlib build-web \
  --manifest-path examples/two_views/Cargo.toml \
  --out-dir examples/two_views/pkg \
  --release \
  --locked
```

The output contains a public `app.js` module, Myplotlib's private loader, and
the bindings and WebAssembly generated by wasm-pack. The host page imports
only `app.js`. The public module exports the cargo-myplotlib release version
and web package format alongside `mount` and `unmount`.

This command expects `wasm-pack` to be installed. Its loader initializes Rayon
when the generated bindings export `initThreadPool`, but the application still
owns the compiler toolchain and flags needed to build threaded WebAssembly. It
does not yet generate standalone HTML or serve the output.
